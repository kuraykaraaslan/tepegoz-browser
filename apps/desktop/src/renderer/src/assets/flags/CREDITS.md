# Turkic region flag assets — sources & licenses

These SVGs are bundled for the **Region** picker (Settings → Language & region) to represent
non-independent Turkic regions/peoples. Each file is named by its 3-letter region code.

Source: **Wikimedia Commons**. Refer to each file's Commons page below for its exact license and
required attribution (most flag SVGs are Public Domain; some are CC — verify before redistribution).
Retrieved 2026-07 for the Tepegöz browser.
