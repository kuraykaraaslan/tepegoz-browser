# Concepts

A **concept** describes what an area is and why: problem, scope and non-goals, vocabulary, the decisions that shaped it (linked ADRs) and its status. It is long-lived and edited as understanding changes. A **phase** is how and when: ordered, checkable work, kept in the concept's own `phases/` folder (`NN-subject.md`, or `NN-subject/` with a `README.md` when it needs several files). An **ADR** (`docs/adr/`) is one decision, written once.

Each concept is a folder: `README.md` (this concept's charter and status), `phases/` (its plan), and where needed `reference/`, `guides/`, `audits/`, `research/`, `assets/`. See the repository documentation layout rule in `internal-ai-rules` (`Documentation_and_Handover_Rules/repository-documentation-layout.md`).
