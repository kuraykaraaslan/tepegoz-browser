| No export path for agent memory/skills (genuinely empty/inert in this build, so nothing is lost by the gap today) | Medium    | Bookmarks (Netscape HTML), stored logins (CSV), browsing history (CSV), the downloads list (CSV), preferences (re-importable JSON), macros (re-importable JSON), scheduled tasks (re-importable JSON — configuration only, never run history or the preapproved-write policy) and trust profiles (re-importable JSON — domain + level only, written through the same tighten-only `setTrustProfile` path a manual change uses) export; the rest can only be moved by copying the whole profile folder, which does NOT carry encrypted data to another machine. | End-to-end suite on a plain Linux/X11 dev machine (2026-10-09)                                                    | Low       | **Every spec passes** (the 5 chat specs that need live accounts skip). It was not always so, and each failure had a cause worth knowing: Playwright's own `keyboard.press` never reaches Electron's `before-input-event`, so shortcut specs use `e2e/send-chord.ts` / `webContents.sendInputEvent`; a popup's `url()` is empty until its first navigation commits, so specs poll it; with no camera, microphone or Web Bluetooth the `platform-defaults` spec asserts the strict denial only where a device exists and notes it otherwise; and `spike-parked-render` caught a REAL bug — starting in the background set the off-screen position before the window was mapped, so on X11 the window manager sometimes placed it on-screen and it stayed there (about 4 launches in 10); it is now parked again once mapped. Practical note: the first launch takes ~33 s here, over the default 30 s test timeout, so pass `--timeout=120000`, and rebuild (`turbo run build --filter=@tepegoz/desktop`) after any source change — the specs run the BUILT app. |
